Nefu Turn Web Pages into Desktop Apps

A lightweight tool that packages your HTML/CSS/JS projects into standalone desktop executables.
No Electron, no Node.js — just double-click to run.

🚀 Quick Start GitHub
Terminal
# Create a new project
$ nefu init my-app
✅ Project 'my-app' created!
# Start the dev server
$ cd my-app && nefu start
🚀 Dev server running at http://localhost:3900
# Package as a desktop app
$ nefu build
✅ Build successful! Output: dist/my-app.exe (8.2 MB)

Why Choose Nefu?

Simple, secure, and efficient — get the best desktop app experience with minimal configuration

🔒

Encrypted Packaging

AES-256-GCM encryption protects your source code, and SHA256 integrity verification ensures files have not been tampered with.

⚡

Hot Reload Development

A built-in dev server auto-refreshes the browser when files change. What you see is what you get, doubling development efficiency.

🎨

.nc Component Language

A unique JSON-based UI description language with 30+ built-in Bootstrap 5 components — drive your interface with data.

🌐

Cross-Platform Support

One codebase, three platforms. Supports Windows, macOS, and Linux, covering all major desktop platforms.

📦

Ultra Lightweight

No bundled Chromium — it uses the system's native WebView. Package size is only a few MB and it launches instantly.

💖

Fully Open Source

Open source under the MIT license, free to use and modify. Active community support with continuous updates.

Three Steps to Get Started

From creation to release, build your first desktop app in as little as 3 minutes

1

Create Project

One command initializes the project structure, auto-generating config files and template code.

$ nefu init my-app
# Generates main.nefu + index.html
2

Develop & Debug

Start the dev server for real-time preview. Files refresh automatically on change.

$ cd my-app
$ nefu start
# Browser opens :3900 automatically
3

Build & Publish

One-click packaging into a standalone executable, ready to distribute to users.

$ nefu build
# ✅ dist/my-app.exe (8.2 MB)
Unique Feature

.nc Component Language

Describe your UI with JSON, and Nefu automatically compiles it into beautiful Bootstrap 5 pages

index.nc
{
  "component": "page",
  "title": "My App",
  "children": [
    {
      "component": "container",
      "children": [
        {
          "component": "alert",
          "type": "success",
          "text": "Welcome!"
        },
        {
          "component": "card",
          "title": "User Info",
          "children": [
            {
              "component": "input",
              "label": "Name",
              "placeholder": "Please enter..."
            },
            {
              "component": "button",
              "text": "Submit",
              "color": "primary",
              "onClick": "lj('submit')"
            }
          ]
        }
      ]
    }
  ]
}
